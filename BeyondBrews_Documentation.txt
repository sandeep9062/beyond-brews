## Project Overview

**Beyond Brews** is a modern e-commerce website for a premium kombucha brand specializing in handcrafted, organic fermented teas. The project showcases a sophisticated blend of modern web technologies to create an engaging shopping experience that emphasizes the brand's commitment to quality, sustainability, and wellness.

### Brand Identity
- **Product**: Small-batch, organic kombucha with unique flavor profiles
- **Target Audience**: Health-conscious consumers, wellness enthusiasts, craft beverage lovers
- **Brand Values**: Sustainability, craftsmanship, community, wellness
- **Design Aesthetic**: Organic luxury with editorial-inspired typography and natural color palette

### Key Selling Points
- 100% organic ingredients
- Small-batch production
- Living probiotics
- Sustainable practices
- Unique flavor profiles (Energizing, Calming, Refreshing, Immunity)

## Technology Stack

### Core Technologies
- **Framework**: Next.js 16.1.6 (App Router)
- **Language**: TypeScript 5.9.3
- **Runtime**: Node.js with Bun package manager
- **Styling**: Tailwind CSS 3.4.17 with custom design system
- **UI Components**: Radix UI + shadcn/ui
- **State Management**: React Context API
- **Data Fetching**: TanStack Query (React Query)
- **Icons**: Lucide React

### Development Tools
- **TypeScript**: Full type safety and development experience
- **ESLint**: Code quality and consistency
- **PostCSS**: CSS processing
- **Autoprefixer**: CSS vendor prefixes
- **Tailwind CSS Typography**: Enhanced text rendering

### Package Management
- **Bun**: Fast JavaScript runtime and package manager
- **Bun.lockb**: Lockfile for deterministic builds

## Data Management

### Product Data Structure
```typescript
interface Product {
  id: string;
  name: string;
  flavor: string;
  price: number;
  tag: 'energizing' | 'calming' | 'refreshing' | 'immunity';
  image: string;
  description: string;
}
```

### Cart State Management
```typescript
interface CartContextType {
  items: CartItem[];
  addToCart: (product: Product) => void;
  removeFromCart: (productId: string) => void;
  updateQuantity: (productId: string, quantity: number) => void;
  clearCart: () => void;
  totalItems: number;
  totalPrice: number;
  isCartOpen: boolean;
  setIsCartOpen: (open: boolean) => void;
}
```

### Data Flow
1. **Static Data**: Products loaded from data/products.ts
2. **Client State**: Cart managed via Context API
3. **Server State**: Future API integration via TanStack Query
4. **Local Storage**: Cart persistence across sessions
